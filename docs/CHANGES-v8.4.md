# UIsername v8.4

Expanded bundled generation vocabulary: English 11,425; Portuguese 5,465;
Spanish 8,149. Includes original entries and broader licensed linguistic lists,
merged by the accent-free username representation. WordNet verb expressions
are concatenated for usernames. Both standard and advanced generators share
these dictionaries. Generation controls show the selected dictionary size.
Vocabulary licenses and source hashes included. App usage requires no dictionary download.

Windows executable compiled with PyInstaller. No automated tests or runtime
UI verification performed for this revision.
